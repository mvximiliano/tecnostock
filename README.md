TecnoStock – Instrucciones

Sistema web de inventario. Caso 1 – Taller de Sistemas de Información.

Nombre: Maximiliano Vergara – Sección 301

Hecho con PHP 8 + PDO, MySQL, Bootstrap 5 y JavaScript, ejecutado en XAMPP.

 Cómo ejecutarlo

1. Copiar la carpeta en `C:\xampp\htdocs\` con el nombre `tecnostock` (si se descargó como ZIP desde GitHub, renombrar `tecnostock-main` a `tecnostock`).
2. Iniciar Apache y MySQL en XAMPP.
3. En phpMyAdmin, importar `database/schema.sql`.
4. Abrir `http://localhost/tecnostock`.

**Usuario:** admin@tecnostock.cl · **Contraseña:** admin123

**Requisitos:** XAMPP 8 o superior (PHP 8 y MySQL sin contraseña, como viene por defecto).
